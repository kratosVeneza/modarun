# Páginas legais adicionadas

Foram adicionadas páginas-base para melhorar a conformidade do app/site Moda Run:

- `/politica-de-privacidade`
- `/termos-de-uso`
- `/politica-de-cookies`
- `/diretrizes-da-comunidade`
- `/exclusao-de-conta`
- `/contato`

Também foi adicionado aviso na página de cadastro com links para Termos de Uso e Política de Privacidade.

Observação: os textos são modelos práticos para o app. Para uso definitivo, recomenda-se revisão jurídica, especialmente se houver pagamentos online, menores de idade, campanhas de marketing, analytics avançado, anúncios personalizados ou integrações com terceiros.
