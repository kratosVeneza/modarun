# Rodapé com links legais

Foi adicionado o componente global `components/FooterLegal.tsx` e ele foi incluído em `app/layout.tsx`.

Agora os links legais aparecem no rodapé do site/app:

- `/politica-de-privacidade`
- `/termos-de-uso`
- `/politica-de-cookies`
- `/diretrizes-da-comunidade`
- `/exclusao-de-conta`
- `/contato`

O rodapé é global, então aparece nas páginas principais, páginas públicas, páginas legais, login/cadastro e demais rotas renderizadas pelo layout principal.
